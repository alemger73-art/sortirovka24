# Sortirovka24 Админ — отдельное приложение

> **Основная сборка:** используйте `app/admin-panel` — там встроенная админка в APK.
> Эта папка (`admin-app`) — Android-обёртка (Capacitor), которую использует `admin-panel` при сборке.

## Быстрый старт

```powershell
cd app/admin-panel
npm install
npm run build:android
```

APK: `app/admin-panel/releases/Sortirovka24-Admin-latest-debug.apk`

Подробная инструкция: [app/admin-panel/README.md](../admin-panel/README.md)
