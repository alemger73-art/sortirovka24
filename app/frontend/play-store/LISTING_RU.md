## Полное описание

```
Sortirovka24 — мобильное приложение для жителей района Сортировка (Караганда).

Что внутри:
• DAM ALEM — заказ еды с доставкой
• Такси по району — вызов машины, отслеживание поездки
• Объявления — продажа, аренда, услуги
• Мастера — найти специалиста или оставить заявку
• Новости, жалобы ЖКХ, справочник, транспорт
• Личный кабинет — заказы, бонусы, профиль

Регистрация по номеру телефона (SMS). Бонусы за регистрацию и заказы.

Приложение создано для жителей района и работает с серверами Sortirovka24.
```
