# Sortirovka24 — готовый APK

## Скачать (актуальная версия)

**Файл для установки:** `Sortirovka24-v1.0.13-debug.apk` или `Sortirovka24-latest-debug.apk`

Версия: **1.0.13** (versionCode 13) — исправлено зависание на экране «Сортировка 24».

## Установка на Android-телефон

1. **Удалите** старую версию приложения с телефона (обязательно!)
2. Скопируйте **Sortirovka24-v1.0.13-debug.apk** на телефон (USB, Telegram, Google Drive и т.д.)
3. На телефоне откройте файл → **Установить**
4. Если система блокирует: **Настройки → Безопасность → Разрешить установку из неизвестных источников** для вашего файлового менеджера

> Не ставьте APK из `android/app/build/outputs/` — используйте файлы из этой папки `releases/`.

## Пересборка (одной командой)

**Если включён `CAPACITOR_SERVER_URL`** — для обычных правок APK пересобирать не нужно, достаточно деплоя на Railway.

Пересборка APK нужна только при смене нативных настроек (иконка, push, новые плагины):

Дважды кликните:
```
app\frontend\scripts\BUILD-ANDROID.bat
```

Или в терминале:
```
cd app\frontend
npm run build:android
```

## iOS

Сборка IPA возможна только на Mac или через GitHub Actions (см. MOBILE_APP.md).
