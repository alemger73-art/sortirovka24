# Sortirovka24 — готовый APK

## Установка на Android-телефон

1. Скопируйте файл **Sortirovka24-latest-debug.apk** на телефон (USB, Telegram, Google Drive и т.д.)
2. На телефоне откройте файл → **Установить**
3. Если система блокирует: **Настройки → Безопасность → Разрешить установку из неизвестных источников** для вашего файлового менеджера

## Пересборка (одной командой)

**Если включён `CAPACITOR_SERVER_URL`** — для обычных правок APK пересобирать не нужно, достаточно деплоя на Railway.

Пересборка APK нужна только при смене нативных настроек (иконка, push, новые плагины):

Дважды кликните:
```
app\frontend\scripts\BUILD-ANDROID.bat
```

Или в терминале:
```
cd app\frontend
npm run build:android
```

## iOS

Сборка IPA возможна только на Mac или через GitHub Actions (см. MOBILE_APP.md).
