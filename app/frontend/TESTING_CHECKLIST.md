# Sortirovka24 — чеклист тестирования перед публикацией

Проверяйте на **реальном Android-телефоне** с APK `Sortirovka24-latest-debug.apk` (v1.0.22+).
Нужен **интернет** (live-режим: UI с Railway).

## Подготовка

- [ ] Удалена старая версия приложения
- [ ] Установлен актуальный APK из `app/frontend/releases/`
- [ ] Railway health: `https://sortirovka24-production-8788.up.railway.app/health` → `healthy`

---

## 1. Запуск и навигация

- [ ] Приложение открывается без белого экрана
- [ ] Splash исчезает, главная загружается
- [ ] Нижнее меню: Главная · DAM ALEM · Объявления · Мастера · Ещё
- [ ] Раздел «Ещё» открывает все ссылки
- [ ] Кнопка «Назад» на Android работает (выход с главной)

## 2. Авторизация

- [ ] Регистрация по SMS (код приходит)
- [ ] Вход существующим аккаунтом
- [ ] Выход из кабинета
- [ ] Сессия сохраняется после перезапуска приложения

## 3. Главная и контент

- [ ] Новости отображаются
- [ ] Баннеры / спецпредложения
- [ ] Жалобы, вакансии (если есть в БД)
- [ ] Переход в новость по клику

## 4. Объявления и каталог

- [ ] Список объявлений
- [ ] Недвижимость
- [ ] Вакансии
- [ ] Мастера — каталог и карточка
- [ ] Справочник

## 5. Еда (DAM ALEM / Гастроном)

- [ ] Меню ресторана, категории
- [ ] Добавление в корзину
- [ ] Оформление заказа (тестовый)
- [ ] Гастроном (если включён)
- [ ] Заказ в парк (если используется)

## 6. Службы

- [ ] Такси — карта / заказ (или корректное «недоступно»)
- [ ] Транспорт — маршруты и остановки
- [ ] Участковые

## 7. Кабинет

- [ ] Профиль пользователя
- [ ] История заказов
- [ ] Бонусы (если есть)

## 8. Медиа и геолокация

- [ ] Фото в объявлениях/меню грузятся
- [ ] Загрузка фото (если доступно пользователю)
- [ ] Геолокация запрашивается и работает (доставка/такси)

## 9. Админка (браузер или с телефона)

- [ ] Вход в `/admin`
- [ ] CRUD новости с публикацией
- [ ] Push → статистика открывается (раздел «Push-уведомления»)
- [ ] Изменения в админке видны в приложении после перезапуска (live-режим)

## 10. Push (после настройки Firebase)

- [ ] `FCM_SERVER_KEY` на Railway
- [ ] `google-services.json` в Android-проекте
- [ ] `VITE_ENABLE_NATIVE_PUSH=true` → пересборка APK
- [ ] Разрешение на уведомления при первом запуске
- [ ] Ручная рассылка из админки
- [ ] Авто-push при публикации новости

---

## Регрессия после деплоя (без нового APK)

1. Внести мелкую правку на фронте → деплой Railway
2. Полностью закрыть приложение → открыть снова
3. Убедиться, что правка видна

---

## Критичные баги — стоп перед публикацией

- Белый/чёрный экран при старте
- Не работает API / пустые списки при рабочем сайте
- Невозможно войти / зарегистрироваться
- Краш при открытии ключевых разделов
