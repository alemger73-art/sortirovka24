## Description (до 4000 символов)
```
Sortirovka24 — мобильное приложение для жителей района Сортировка (Караганда). Всё, что нужно району, в одном месте.

Что внутри:
• DAM ALEM — заказ еды с доставкой на дом
• Такси по району — вызов машины и отслеживание поездки на карте
• Объявления — покупка, продажа, аренда и услуги соседей
• Мастера — найдите специалиста или оставьте заявку на услугу
• Новости района и жалобы по ЖКХ
• Справочник организаций и транспорт
• Личный кабинет — история заказов, бонусы и профиль

Регистрация по номеру телефона с подтверждением по SMS. Начисляем бонусы за регистрацию и заказы.

Приложение создано для жителей района и работает с серверами Sortirovka24. Геолокация используется только по вашему запросу — для определения адреса доставки и вызова такси.
```
