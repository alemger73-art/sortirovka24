# DAM ALEM — короткая инструкция

## Для клиента: как заказать за 4 шага

1. **Выберите блюдо** — нажмите на карточку или красную кнопку **+**. Если есть опции (соус, размер) — выберите их и нажмите «В корзину».
2. **Корзина** — внизу экрана красная полоска «Корзина». Нажмите, проверьте состав.
3. **Оформление** — укажите имя и телефон, выберите **доставку** или **самовывоз**, при доставке — **зону** (от неё зависит цена), способ **оплаты**.
4. **Готово** — появится экран «Заказ принят» с номером. Статус — в **личном кабинете** (войти по телефону).

### Иконки на странице

| Иконка | Значение |
|--------|----------|
| 🚚 Грузовик | Доставка на адрес |
| 🏪 Магазин | Самовывоз (бесплатно) |
| 💵 / 📱 | Наличные, Kaspi QR или Halyk QR |
| 📍 Карта | Зона доставки — выберите свой район |
| + / − | Добавить или убрать порцию |

### Зоны доставки

Цена доставки зависит от выбранной зоны при оформлении. Клиент видит список зон и стоимость **до** подтверждения заказа.

### Оплата

- **Наличные** — оплата курьеру при получении.
- **Kaspi QR / Halyk QR** — QR на экране после заказа; можно оплатить при получении.

## Для владельца: админка

Открыть: **Админ → DAM ALEM** (`/admin?tab=dam-alem`)

| Вкладка | Что делать |
|---------|------------|
| **Заведение** | Название, фото, рейтинг, время доставки, описание (видно клиентам) |
| **Блюда** | Меню: цена, фото, вес, «хит», комбо |
| **Категории** | Разделы меню (пицца, суши…) |
| **Опции** | Модификаторы: соусы, размеры |
| **Заказы** | Новые заказы, смена статуса, поиск, выручка за день |
| **Баннеры** | Акции на главной `/food` |
| **Настройки** | WhatsApp, мин. заказ, **зоны доставки** (JSON), сервисный сбор % |

### Зоны доставки (настройки)

Пример в «Настройки → Зоны доставки»:

```json
[
  { "name": "Сортировка (центр)", "radius_km": 2, "price": 500 },
  { "name": "Дальние улицы", "radius_km": 5, "price": 800 }
]
```

Клиент выбирает зону вручную при оформлении. Название и цена должны совпадать с тем, что в админке.

### Статусы заказа

| Статус | Действие |
|--------|----------|
| Новый | Поступил заказ — Telegram уведомление |
| Готовится | Приняли в работу |
| Доставлен | Заказ завершён |
| Отменён | Клиент отказался / нет товара |

При смене статуса — уведомление в Telegram.

### FrontPad (касса)

Ссылка внизу раздела DAM ALEM → **FrontPad**. Синхронизация меню с кассой (нужна настройка API).

## Частые вопросы

**Клиент не видит новое блюдо** — сохраните в админке; страница `/food` обновится при следующем открытии или фокусе вкладки.

**Заказ не в Telegram** — проверьте `TELEGRAM_BOT_TOKEN_FOOD` и `TELEGRAM_CHAT_ID_FOOD` на сервере.

**Сумма не сходится** — цены и зоны должны совпадать с каталогом; клиенту: обновить страницу.
