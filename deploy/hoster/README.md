# Переезд Сортировки24 на Hoster.kz (Казахстан)

Цель: сайт и база с персональными данными — на серверах в РК (ст. 12 п. 2 Закона РК «О персональных данных»).

## Серверы
| Роль | Тариф Hoster.kz | Цена | Что на нём |
|---|---|---|---|
| main | Cloud 2-4-100 (2 vCPU, 4 ГБ, 100 ГБ NVMe), Ubuntu 24.04 | 9 600 ₸/мес | Caddy → сайт (Docker) → PostgreSQL 18 |
| backup | Cloud 1-1-25, Ubuntu 24.04, другой город | 3 100 ₸/мес | только зашифрованные бэкапы базы |

Доступ: SSH-ключ `sortirovka24-deploy` (закрытая часть — у владельца, `D:\Projects\_keys`). Пароли не используются.

## Что где хранится после переезда
- База (клиенты, заказы, бонусы, аккаунты) — main, Docker-том `s24_db-data`.
- Бэкапы — шифруются ключом `age` (закрытый ключ только у владельца), копия на backup, 30 дней; локально 7 дней.
- Секреты — `/opt/s24/.env` (chmod 600), переносятся из переменных Railway.
- Фото — пока Cloudinary; персональные фото (документы курьеров, жалобы, аватары) — второй этап.
- Домен/защита — Cloudflare; код — GitHub.

## Порядок работ
1. `bootstrap.sh main` на main, `bootstrap.sh backup` на backup.
2. Cloudflare → SSL/TLS → Origin Server → создать сертификат для `sortirovka24.kz, *.sortirovka24.kz` →
   `/opt/s24/certs/origin.pem`, `origin-key.pem`. Режим SSL: Full (strict).
3. `/opt/s24/.env` по `.env.example` (значения из Railway).
4. `deploy.sh main` — сборка и запуск, проверка `/health/ready`.
5. Пробный перенос: дамп Railway → `pg_restore` в новую базу → проверка сайта по IP через hosts-файл.
6. Ночью: режим «только чтение» не нужен, перерыв ~30 мин: финальный дамп → восстановление → DNS `www`/`@` в Cloudflare на IP main (оранжевое облако).
7. Мониторинг 1 час; откат — вернуть DNS на Railway.
8. Cron: `backup.sh` каждый час (`0 * * * *`), проверка бэкапа — агент «Дозор».
9. Через неделю — отключить Railway.

## Обновление сайта
`bash /opt/s24/deploy.sh main` — собирает, запускает, при неуспешной проверке здоровья автоматически
возвращает предыдущую версию.

## Восстановление после аварии
Новый сервер → `bootstrap.sh main` → `.env` и сертификат → `deploy.sh main` →
`restore.sh <последний бэкап> <ключ age>` → DNS на новый IP. Ожидаемо ~1 час.
