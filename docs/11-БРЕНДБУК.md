## 3. Цветовая палитра

### Основные цвета

| Token | HEX | Использование |
|-------|-----|---------------|
| **Primary Blue** | `#2563EB` | PWA theme, ссылки, акценты web |
| **Dark Navy** | `#0B0F19` | Dark mode фон, native splash |
| **Dark Surface** | `#111827` | Градиенты splash, карточки dark |
| **Yellow Accent** | `#FACC15` (yellow-400) | CTA такси, кабинет, акценты «район» |

| **Light BG** | `#F8FAFC` / `#f5f5f5` | Light mode фон |
| **White** | `#FFFFFF` | Карточки light mode |

### Семантические

| Цвет | Назначение |
|------|------------|
| Green | Успех, «online», доставлено |
| Red | Ошибка, отмена, destructive |
| Slate/Gray | Текст secondary, admin panel |

### CSS variables (shadcn)
Primary UI использует HSL tokens в `index.css`: `--primary`, `--background`, `--foreground`. Не хардкодить hex в новых компонентах — предпочитать Tailwind tokens.

## 5. UI-паттерны

### Mobile-first
- Bottom navigation на главных экранах
- Safe area: `env(safe-area-inset-top/bottom)`
- Touch targets ≥ 44px

### Карточки
- `rounded-2xl`, мягкая тень
- Hover на desktop; active scale на mobile

### Кнопки
- Primary action: blue или yellow (контекст: taxi/cabinet → yellow)
- Secondary: outline / ghost
- Destructive: red variant shadcn

### Dark mode
- Toggle в header
- `dark:` классы везде для фона и текста
- Native splash: always dark gradient

### Loading
- Skeleton pulse на web
- Branded splash на native (icon + yellow bar)

## 6. Tone of Voice (вербальный стиль)

### Принципы
- **На «вы»** к пользователю (уважительно, но не официоз)
- **Коротко** — житель читает с телефона
- **Локально** — «район», «соседи», «Сортировка», не «наша платформа мирового уровня»
- **Честно** — если сервис бета или платный, сказать прямо

### Примеры

| ❌ Не так | ✅ Так |
|----------|--------|
| Осуществите авторизацию | Войдите по номеру телефона |
| Маркетплейс услуг | Сервисы вашего района |
| Error 500 | Не удалось загрузить. Попробуйте ещё раз |
| DAM ALEM International Food Platform | DAM ALEM — доставка еды |

### Языки
- Русский — основной для UI и сторов
- Казахский — полный параллельный перевод ключевых экранов (`translations.ts`)
- Бренд **DAM ALEM**, **Sortirovka24** — не переводить

## 11. Do / Don't

### ✅ Do
- Использовать «Sortirovka24» или «Сортировка 24» последовательно
- Показывать локацию «Караганда, Сортировка»
- Тестировать в light и dark mode
- Проверять KZ перевод при новых строках

### ❌ Don't
- Менять app id `kz.sortirovka24.app`
- Использовать чужие логотипы партнёров без разрешения
- Gradient overload на каждом экране
- ALL CAPS в body text (только logo/header)
