# Глоссарий Sortirovka24

---

## География и бренд

| Термин | Значение |
|--------|----------|
| **Сортировка** | Микрорайон в городе Караганда, Казахстан |
| **Sortirovka24 / Сортировка 24** | Название платформы и приложения |
| **Супер-приложение** | Единое приложение с множеством модулей (super-app) |

---

## Приложения и идентификаторы

| Термин | Значение |
|--------|----------|
| `kz.sortirovka24.app` | Application ID основного Android/iOS приложения |
| `kz.sortirovka24.admin` | Application ID админ-приложения |
| **PWA** | Progressive Web App — установка сайта на главный экран |
| **APK** | Android package (debug для тестов) |
| **AAB** | Android App Bundle для Google Play |
| **Capacitor** | Фреймворк обёртки web → native |

---

## Технические термины

| Термин | Значение |
|--------|----------|
| **FastAPI** | Python web-фramework для REST API |
| **Vite** | Сборщик frontend |
| **Alembic** | Миграции схемы БД |
| **JWT** | JSON Web Token — сессия без server-side state |
| **ORM** | SQLAlchemy — объектно-реляционное отображение |
| **web-sdk** | `@metagptx/web-sdk` — клиент API |
| **Lazy load** | Отложенная загрузка JS-страниц |
| **Module guard** | `require_module` — блокировка API выключенного модуля |
| **Fail open** | При ошибке БД модуль остаётся доступен (не скрывается случайно) |

---

## Бизнес-модули

| Термин | Значение |
|--------|----------|
| **DAM ALEM** | Бренд доставки еды в районе; интеграция с FrontPad |
| **FrontPad** | Облачная касса/POS; синхронизация меню и заказов |
| **Гастроном** | Модуль продуктового магазина с доставкой |
| **Прораб** | Модуль стройматериалов и услуг |
| **Park / Food Park** | Заказ еды с привязкой к точкам на карте парка (SVG) |
| **Park points** | Точки выдачи/доставки на карте парка |
