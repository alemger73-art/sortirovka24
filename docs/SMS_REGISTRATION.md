# SMS-регистрация Sortirovka24

Провайдер: Mobizon Kazakhstan (`https://mobizon.kz`).

## Подключение

1. Зарегистрировать аккаунт Mobizon и подтвердить телефон и email.
2. Пополнить баланс для тестовых сообщений.
3. В профиле Mobizon включить доступ к API и создать отдельный API-ключ для Sortirovka24.
4. Обратиться в поддержку Mobizon для подключения мгновенных транзакционных SMS без ручной модерации. Пример текста: `Sortirovka24 kod: 123456`.
5. При необходимости зарегистрировать имя отправителя `SORTIROVKA24`. До его одобрения использовать общую подпись Mobizon.
6. Добавить переменные в production-сервис Railway:

```text
SMS_PROVIDER=mobizon
MOBIZON_API_KEY=<секретный ключ из Mobizon>
MOBIZON_API_URL=https://api.mobizon.kz
MOBIZON_SENDER=<одобренная подпись или пусто>
SMS_EXPOSE_CODE=false
SMS_RESEND_COOLDOWN_SECONDS=60
SMS_MAX_REQUESTS_PER_WINDOW=6
SMS_REQUEST_WINDOW_MINUTES=15
DEBUG=false
```

`MOBIZON_API_KEY` нельзя добавлять в Git, frontend или сообщения. Его следует вводить непосредственно в Railway Variables.

## Проверка после подключения

1. Открыть `/register` в приватном окне.
2. Ввести свой телефон Казахстана и запросить код.
3. Убедиться, что шестизначный код пришёл по SMS и не показан на странице или в ответе API.
4. Проверить блокировку повторной отправки на 60 секунд.
5. Проверить неправильный код, просроченный код и ограничение после пяти ошибок.
6. Завершить регистрацию и проверить вход после выхода и перезагрузки страницы.
7. Проверить баланс и статус доставки сообщения в кабинете Mobizon.
