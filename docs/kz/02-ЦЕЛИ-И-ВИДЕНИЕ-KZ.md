# Sortirovka24 мақсаты мен көкжиегі

---

## Миссия

**Сортировка шағын ауданының күнделікті сервистерін бір ыңғайлы қосымшада біріктіру**, сонда тұрғындар шебер іздеуге, тамақ тапсырыс беруге, такси шақыруға және быттық сұрақтарды шешуге аз уақыт жұмсасын — ал жергілікті бизнес аудиториямен тікелей байланыса алсын.

---

## Көкжiek (3–5 жыл)

Сортировка 24 ауданның **«цифрлық кіреберісі»** болады: қосымшаны ашасыз — ауа-райы, ЖК жаңалықтары, түскі ас тапсырысы, такси, участковый немесе сантехникке өтінім — бәрі бір жерде. Платформа **модульді** өседі: жаңа сервистер бүкіл қосымшаны қайта жазбай қосылады.

---

## Мақсатты аудитория

### Негізгі
- **Сортировка** шағын ауданы тұрғындары, Қарағанды
- Смартфон пайдаланушылары
- Тілдер: орыс (негізгі), қазақ

### Қосымша
- DAM ALEM, Гастроном, Прораб, дәріхана сияқты жергілікті бизнес
- Шеберler мен сұлулық салондары
- Такси жүргізушілері мен тамақ курьерлері
- Контент модераторлары

## Стратегиялық мақсаттар

### Өнім
1. **Retention:** тұрғын аптасына 2–3 рет кірсін
2. **Қамту:** белсенді үйlerдің көбі қосымша туралы бilsin
3. **Тіркелу:** оңай SMS + `WELCOME_BONUS_POINTS`
4. **Тамақ циклі:** себет → Telegram → курьer → FrontPad

### Техникалық
1. API uptime ≥ 99%
2. Басты бет tez жүктеледі
3. Бір backend — web, PWA, Android, iOS, Admin APK
4. Alembic миграциялары
