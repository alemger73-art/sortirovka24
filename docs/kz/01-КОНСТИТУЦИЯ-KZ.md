# Sortirovka24 жоба конституциясы

> Бұл құжат — жобаның «жарғысы». Ол **неге** бар екенімізді, шешімдерді **қалай** қабылдайтынымызды және техникалық түрде мүмкін болса да **не істемейтінімізді** анықтайды.

---

## 1. Платформаның мақсаты

Sortirovka24 — **Сортировка** шағын ауданының (Қарағанды қ., Қазақстан) **жергілікті цифрлық инфрақұрылымы**. Біз «барлығына арналған» универсалды маркетплейс немесе әлеуметтік желі болуға талпынбаймыз. Біздің жауапкершілік аймағы — **нақты аудан тұрғындарының күнделікті қажеттіліктері** және жергілікті бизнес, басқару компаниялары мен сервистермен байланыс.

---

## 2. Негізгі принциптер

### 2.1. Масштабтан бұрын — локалдılıq
- Әр функция **Сортировка тұрғынына** нақты пайдасы бар болуы керек.
- Жаңа модуль тек аудан немесе серіктестердің нақты мәселесін шешсе ғана қосылады.

### 2.2. Бір кіру — көптеген сервистер
- Тұрғын **бір рет** тіркеледі (телефон / Google) және барлық қосылған модульдерге кіреді.
- Жеке кабинет заказдарды, бонустарды, рөлдерді (шебер, жүргізуші, курьер, серіктес) біріктіреді.

### 2.3. Модульділік және басқару
- Әр ірі блок (тамақ, такsi, хабарландырулар...) — **бөлек модуль**, админ арқылы қосу/өшіру мүмкін.
- Өшірілген модуль интерфейстен **және** API деңгейінде блокталады (админ除外).

### 2.4. Қолжетімділік және тілдер
- Интерфейс **орыс және қазақ** тілдерін қолдайды.
- Басты аудитория — смартфон; мобильді дизайн — басым.

### 2.5. Қауіпсіздік және сенім
- JWT, SMS (Mobizon), Google OAuth.
- API кілттері **тек серверде** — фронтендте емес.

### 2.6. Ақауға төзімділік
- БД уақытша қолжетімсіз болса да сервер іске қосылады.
- Желіде қате болғанда пайдаланушы автоматты түрде шығарылмайды.

## 3. Шекаралар (не істемейміз)

| Істемейміз | Неге |
|------------|------|
| Ауданға байланысыз глобалды маркетплейс | Миссия мен ресурстар шашыратылады |
| Карта деректерін өз серверімізде сақтау | Stripe / қолма-қол |
| Модерациясыз контент (қажет жерлерде) | Шағымдар, хабарландырулар |
| API-де breaking change мобильді клиенттерсіз | Alembic + үйлесімділік |

## 5. Экожүйедегі рөлдер

| Қатысушы | Күтілетін нәтиже |
|----------|-------------------|
| **Тұрғын** | Шебер табу, тамақ/taksi заказ, шағым, жаңалықтар |
| **Шебер / жүргізуші / курьер** | Заказдар мен статустар бар кабинет |

## 6. Сапа стандарттары

- **Frontend:** React 18, TypeScript, Tailwind, shadcn/ui
- **Модуль slug:** ағылшынша; UI мәтіні — RU/KZ
