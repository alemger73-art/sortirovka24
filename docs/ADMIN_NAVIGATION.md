# Навигация админки

Адрес панели: `/admin`. Права доступа и серверные проверки не изменены.

## Где искать разделы

- **Центр управления** — очередь новых заявок и модерации. Сначала видны разделы с задачами; кнопка «Показать все разделы сводки» раскрывает остальные счётчики.
- **Публикации** — новости, баннеры, жалобы, история района.
- **Объявления и каталог** — объявления, недвижимость, вакансии, мастера, салоны, вызовы и подключение мастеров.
- **Еда и доставка** — DAM ALEM 2.0, точки парка, заказы в парк.
- **Район и службы** — справочник, участковые, такси, курьеры, автобусы.
- **Партнёры** — заявки бизнеса и кабинеты магазинов.
- **Настройки сайта** — видимость разделов, счётчики на главной, категории каталога, реквизиты поддержки, рассылка, логин и пароль.

Поиск находится над меню. Для DAM ALEM можно искать также «алем», «заказы», «касса», «POS», «Telegram». Настройки кассы доступны внутри DAM ALEM → Настройки → Учёт / API.

Удалены только повторные пункты навигации DAM ALEM и POS. Данные, страницы и бизнес-функции сохранены. Старые ссылки `partners-alem-food`, `food`, `food-orders`, `food-settings`, `pos-integration` перенаправляются в единый кабинет. Ссылки вида `/admin?section=food-orders&order=71` сохраняют номер заказа.

## Поведение при ошибках

- Ошибка сводки показывается отдельно от пустой очереди. Если данные уже были загружены, они остаются с предупреждением об устаревании.
- Запоздавший HTTP-ответ не заменяет более свежую сводку, полученную во время запроса.
- Сбой проверки входа не удаляет сохранённую сессию; доступна повторная проверка.
- Ошибка отдельной страницы оставляет меню доступным.
- После неудачной загрузки видимости разделов, реквизитов, счётчиков, такси, курьеров и рассылки предлагается повторная загрузка.
- Рассылка недоступна, пока сервис не подключён. Технические инструкции свёрнуты.

## Проверка изменений

Из `app/frontend`:

```powershell
node node_modules/typescript/bin/tsc -b
$env:VITE_APP_LOGO_URL='/icon-512.png'
node node_modules/vite/bin/vite.js build --mode mobile --outDir dist-admin-check
$env:ADMIN_BUILD_DIR='dist-admin-check'
node node_modules/@playwright/test/cli.js test --config playwright.admin-navigation.config.ts --grep 'admin|inspector address editing|new inspector'
```

Проверки выполняются в Chrome на ширинах 320, 768 и 1440 пикселей. Они охватывают открытие 31 раздела, горизонтальное переполнение, шесть редакторов публикаций, поиск меню, Escape и возврат фокуса, совместимость старых ссылок, сбои сводки и входа, сохранение данных справочника, участковых и автобусов.

API в браузерных тестах подменён тестовыми ответами. Эти проверки не заменяют проверку производственной базы, реальных платежей, отправки уведомлений и каждой операции во всех подразделах. Миграций базы и публикации на сервер в этом изменении нет.
