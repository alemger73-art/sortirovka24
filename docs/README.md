## О проекте в одном абзаце

**Sortirovka24** — цифровая платформа для жителей микрорайона Сортировка: еда с доставкой (DAM ALEM), такси, объявления, мастера, новости, транспорт, справочник и личный кабинет. Доступен как веб-сайт (PWA), нативное приложение Android/iOS и отдельное админ-приложение. Интерфейс — русский и казахский языки.

## Версия документации

- **Дата:** июнь 2026  
- **Приложение:** `kz.sortirovka24.app`  
- **Админ-приложение:** `kz.sortirovka24.admin`  
- **Бэкенд:** FastAPI на Railway (или AWS Lambda)  
- **База:** PostgreSQL (прод) / SQLite (локально)
