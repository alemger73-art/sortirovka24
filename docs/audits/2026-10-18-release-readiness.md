# Сортировка24 — оценка проекта и готовность к релизу (2026-10-18)

Основа: `main` = код сайта (сборка `s24-deletion-20261016-56`), Railway `dependable-solace`, проверки 18.10.2026.

## Масштаб
- ~150 тыс. строк: бэкенд Python ~74k (531 файл), фронтенд TS/TSX ~77k (492 файла).
- 81 модуль API, 81 модель данных, 72 миграции, 94 страницы, 100 файлов тестов.
- Стек: FastAPI + SQLAlchemy async + PostgreSQL 18; React 18 + Vite + Tailwind; Capacitor (Android 1.0.31, iOS 1.0.27).
- Модули: DAM ALEM (доставка, касса, курьеры, CRM, бонусы, зарплата), новости, объявления, недвижимость, работа,
  мастера, салоны, аптека, гастроном, стройматериалы (Прораб), Волна, такси, транспорт, справочник, инспекторы,
  жалобы, поддержка, кабинеты клиента/партнёра/мастера, админка, push, Telegram/WhatsApp.

## Блокеры релиза
1. **Учёт наличных курьера** (аудит DAM #1): наличные попадают в кассу, пока они у курьера.
2. **Бэкапы БД**: ежедневная копия только на ПК владельца, пропуски 6, 7, 8, 10, 17 октября; копии вне ПК нет.
   Нужно: включить бэкапы Railway Postgres + автоматическая проверка, что копия создалась.
3. **Capacitor 7.2 → ≥7.6.9** (критическая уязвимость: чужой контент может загрузиться в приложение).
   Обязательно до публикации в магазинах.
4. **Мониторинг ошибок**: `SENTRY_DSN` / `VITE_SENTRY_DSN` не заданы — об ошибках у клиентов никто не узнает.
