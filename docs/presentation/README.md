# Презентация Sortirovka24 (PDF)

Красивая презентация проекта на **12 слайдов** — для показа инвесторам, партнёрам, жителям, команде.

## Файлы

| Файл | Описание |
|------|----------|
| `sortirovka24-presentation.html` | Презентация (открыть в браузере) |
| `Sortirovka24-Presentation.pdf` | PDF (после генерации) |
| `generate-pdf.ps1` | Скрипт автоматической генерации PDF |

## Быстрый старт

### Вариант 1 — автоматически (Windows)

```powershell
cd docs\presentation
powershell -ExecutionPolicy Bypass -File generate-pdf.ps1
```

Скрипт создаст `Sortirovka24-Presentation.pdf` и откроет его.

### Вариант 2 — вручную через браузер

1. Откройте `sortirovka24-presentation.html` в Chrome или Edge
2. **Ctrl+P** → «Сохранить как PDF»
3. **Ориентация:** альбомная (Landscape)
4. **Включить:** «Фоновая графика» / Background graphics
5. Сохранить как `Sortirovka24-Presentation.pdf`
