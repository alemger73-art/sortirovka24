# Презентация Sortirovka24

**Story-driven презентация** с mockup-ами телефона, планшета и ноутбука, историей жительницы Айгуль и эмоциональным user journey (заказ → доставка → радость).

## Файлы

| Файл | Описание |
|------|----------|
| `sortirovka24-presentation.html` | 10 слайдов — открыть в браузере |
| `Sortirovka24-Presentation.pdf` | PDF после генерации |
| `generate-pdf.ps1` | Автосборка PDF |

## Сгенерировать PDF

```powershell
cd docs\presentation
powershell -ExecutionPolicy Bypass -File generate-pdf.ps1
```

Или: откройте HTML → **Ctrl+P** → альбомная → **фоновая графика** → сохранить PDF.

## Слайды

1. **Обложка** — три телефона, tagline
2. **Три устройства** — смартфон, планшет, ноутбук
3. **История Айгуль** — утро, главная
4. **Заказ DAM ALEM** — меню + корзина
5. **Курьер в пути** — трекинг
6. **Доставлено!** — эмоция, бонусы, звёзды
7. **Планшет + ПК** — объявления, админка
8. **Было → Стало** — трансформация района
9. **Вся экосистема** — модули
10. **Финал** — «цифровой дом для своих»

## Совет

Для живого показа откройте HTML в Chrome на полный экран (**F11**) и листайте колёсиком или стрелками — слайды идут вертикально.
