01 — Миссия

Зачем существует Sortirovka24

Объединить повседневные сервисы микрорайона Сортировка в одном удобном приложении — чтобы жители тратили меньше времени на бытовые задачи, а местный бизнес получал прямой канал связи с аудиторией.
🏘️

Локальная инфраструктура

Не универсальный маркетплейс «для всех», а цифровой портал конкретного района с его ЖКХ, автобусами, магазинами и соседями.

📱

Один вход — много сервисов

Одна регистрация по SMS или Google. Личный кабинет: заказы, бонусы, роли мастера, водителя, курьера, партнёра.

05 — Экосистема

Кто пользуется платформой

👤 Житель

Заказы, объявления, новости, кабинет с бонусами. Регистрация по SMS (+300 бонусов) или Google.

🔧 Мастер · 💇 Салон

Кабинет с заявками, профиль, модерация «стать мастером».

🏪 Партнёр (seller)

Гастроном, Прораб, аптека — витрина и заказы в кабинете партнёра.

🚕 Водитель · 📦 Курьер

Online/offline, GPS, приём заказов. Заявки одобряет админ.

🍳 Оператор DAM ALEM

Telegram-бот: новый заказ → подтверждение → FrontPad (касса).

🛡️ Администратор

Web `/admin` + отдельное APK `kz.sortirovka24.admin`. Контент, модули, push, статистика.

07 — Конституция проекта

Принципы, которым следуем

  • Локальность — польза для Сортировки, не «для всего KZ»
  • Модульность — kill-switch модулей в админке
  • Безопасность — JWT, секреты только на сервере
  • Устойчивость — retry, health-check, fail-open
  • Два языка — русский и казахский интерфейс
  • Mobile-first — большинство с телефона
  • Один бэкенд — web, APK, admin APK
  • Документированность — docs/ как источник правды
Sortirovka24 — для своих, в своём районе.
