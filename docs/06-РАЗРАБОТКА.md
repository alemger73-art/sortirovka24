## Первый запуск (Windows)

### Backend

```powershell
cd app\backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python main.py
```

API: http://127.0.0.1:8000  
Health: http://127.0.0.1:8000/health

При первом запуске: SQLite `dev.db`, seed из `mock_data/`, admin user.

### Frontend

```powershell
cd app\frontend
pnpm install
pnpm run dev
```

UI: http://localhost:3000  
Proxy `/api` → `:8000`

### Admin (браузер)

```powershell
cd app\frontend
pnpm run dev:admin
```

Admin UI: http://localhost:3100

## Переменные окружения

### Backend (`app/backend/.env`)

Минимум:
```env
DATABASE_URL=sqlite+aiosqlite:///./dev.db
ENVIRONMENT=development
```

Полный список: `app/backend/.env.example`

### Frontend mobile (`.env.mobile`)

```env
VITE_API_BASE_URL=https://your-backend.up.railway.app
```

Копировать из `.env.mobile.example` перед `build:mobile`.

## Соглашения по коду

### Backend

```
routers/   → HTTP only, Depends, HTTPException
services/  → business logic, DB transactions
models/    → SQLAlchemy columns
schemas/   → Pydantic request/response
```

- Async everywhere (`async def`, `AsyncSession`)
- Новый router → регистрация в `main.py` (или auto-import если настроено)
- Модуль → `require_module("slug")` на router

### Frontend

```
pages/       → route-level components
components/  → reusable UI
lib/         → api, cache, utils
hooks/       → data fetching hooks
config/      → modules, constants
```

- Lazy import страниц в `App.tsx`
- Переводы через `useLanguage()` / `translations.ts`
- API calls через `client` из `lib/api.ts` + `withRetry`

### Sync modules list

При добавлении модуля обновить **оба** файла:
- `app/backend/services/module_settings.py` → `MODULE_KEYS`
- `app/frontend/src/config/modules.ts` → `MODULE_DEFS`

## Отладка

### Backend logs
- Локально: `app/backend/logs/app_*.log`
- Railway: dashboard logs

### Frontend
- React DevTools
- Network tab → `/api/v1/*`
- `VITE_*` env только при сборке (restart dev после изменения)

### Типичные ошибки dev

| Ошибка | Решение |
|--------|---------|
| CORS | Проверить backend запущен на :8000 |
| 503 API | Backend cold start; `warmupBackend()` |
| Module 404 | Модуль выключен в Admin → Modules |
| Empty data | SQLite seed; проверить mock_data |

## Git workflow (рекомендация)

1. Feature branch от main
2. Малые PR с описанием «зачем»
3. Не коммитить `.env`, keystore, `releases/*.apk` (если не нужно)
4. Перед merge — `pnpm run typecheck`, `pnpm run lint`
