|-----------|----------|---------|-----|

Production URL (пример): `https://sortirovka24-production-8788.up.railway.app`

## Деплой бэкенда (Railway)

### 1. Создать проект Railway
- **SPA+API (www / один URL):** Root Directory пустой (`/`) → корневой `Dockerfile`
- **API-only:** Root Directory `app/backend` → `app/backend/Dockerfile` + `start.sh`
- Root Directory задаётся только в Railway dashboard (из git не меняется)
- Добавить PostgreSQL plugin → `DATABASE_URL`

### 2. Обязательные переменные

| Переменная | Назначение |
|------------|------------|
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_SECRET_KEY` | 32+ случайных символов |
| `ADMIN_PASSWORD` | Пароль `/admin` |
| `ENVIRONMENT` | `production` |
| `CLOUDINARY_CLOUD_NAME` | Upload фото |
| `CLOUDINARY_API_KEY` | Upload фото |
| `CLOUDINARY_API_SECRET` | Upload фото |
| `MOBIZON_API_KEY` | SMS |
| `SMS_PROVIDER` | `mobizon` |

Полный список: `app/backend/.env.example`, [PRODUCTION_CHECKLIST.md](../PRODUCTION_CHECKLIST.md)

### 3. Проверка

```bash
curl https://YOUR-RAILWAY-URL/health
```

Ожидается:
```json
{"status":"healthy","database":"ok"}
```

### 4. Миграции

При деплое или вручную:
```bash
alembic upgrade head
```

## Мобильные релизы

### Debug APK для тестеров

```powershell
cd app\frontend
pnpm run build:android
# → releases/Sortirovka24-latest-debug.apk
```

**Важно:** удалить старую версию перед установкой новой.

### Google Play (AAB)

1. Keystore: `pnpm run setup:play-keystore`
2. Release: `pnpm run build:android:release`
3. Upload: `releases/Sortirovka24-release.aab`
4. Privacy URL: `https://YOUR-DOMAIN/privacy.html`

Инструкция: [PLAY_STORE.md](../app/frontend/play-store/PLAY_STORE.md)

### Admin APK

```powershell
cd app\admin-panel
npm run build:android
# → Sortirovka24-Admin-latest-debug.apk
```

## FrontPad (DAM ALEM)

1. Задать `FRONTPAD_*` на Railway
2. `FRONTPAD_SYNC_ON_START=true` — первичная синхронизация меню
3. `FRONTPAD_AUTO_PUSH_ORDERS=true` — автоотправка заказов
4. Telegram webhook для кнопок оператора

Документация: [RAILWAY_FRONTPAD.md](../app/backend/docs/RAILWAY_FRONTPAD.md)

## Telegram bots

| Бот | Env prefix | Назначение |
|-----|------------|------------|
| Общий | `TELEGRAM_BOT_TOKEN` | Базовые уведомления |
| Food ops | `TELEGRAM_*_FOOD` | Заказы DAM ALEM |
| Couriers | `TELEGRAM_*_FOOD_COURIER` | Курьеры |
| Taxi | `TELEGRAM_*_TAXI` | Поездки |
| Gastronom | `TELEGRAM_*_GASTRONOM` | Заказы гастронома |

Webhook:
```
POST https://YOUR-DOMAIN/api/v1/telegram/webhook
secret_token: TELEGRAM_WEBHOOK_SECRET
```

`PUBLIC_FRONTEND_URL` — ссылки «редактировать заказ» в сообщениях.

## Push-уведомления

1. Firebase Console → Server key → `FCM_SERVER_KEY` на Railway
2. `google-services.json` в `android/app/`
3. `.env.mobile`: `VITE_ENABLE_NATIVE_PUSH=true`
4. Пересборка APK
5. Админ → Система → Push

Авто-push: при публикации новости.

## Типичные проблемы (prod)

| Симптом | Причина | Решение |
|---------|---------|---------|
| Пустые новости в APK | Неверный `VITE_API_BASE_URL` | Исправить `.env.mobile`, rebuild |
| Фото не грузятся | Нет Cloudinary | Добавить `CLOUDINARY_*` |
| SMS не приходит | Mobizon ключ / баланс | Проверить dashboard Mobizon |
| Logout после деплоя | Сменился JWT secret | Фиксированный `JWT_SECRET_KEY` |
| Белый экран | JS error | Обновить APK (ErrorBoundary) |
| FrontPad не синхронизирует | Неверный secret | Admin → FrontPad, logs |
| 404 на модуль | Выключен в Modules | Включить или это ожидаемо |
