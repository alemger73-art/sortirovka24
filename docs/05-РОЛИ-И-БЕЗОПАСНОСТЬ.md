# Роли и безопасность

---

## Две системы аутентификации

Sortirovka24 использует **раздельные** механизмы для жителей и админ-панели.

| Система | Кто | Endpoint | Token storage |
|---------|-----|----------|---------------|
| **Account (жители)** | Пользователи приложения | `/api/v1/account/*` | localStorage account JWT |
| **Admin panel** | Операторы контента | `/api/v1/admin-auth/*` | `_sp924_token` |

Оба используют JWT, но payload и проверки различаются.

---

## Роли жителей (`AccountUser.role`)

| Роль | Описание | Кабинет |
|------|----------|---------|
| `user` | Обычный житель | `/cabinet` |
| `master` | Подтверждённый мастер | `/cabinet/master` |
| `driver` | Водитель такси | `/cabinet/driver` |
| `seller` | Партнёр (магазин) | `/cabinet/partner` |
| `moderator` | Модератор контента | `/cabinet/admin` (ограниченно) |
| `admin` | Администратор аккаунт-системы | `/cabinet/admin` |
| `superadmin` | Полный доступ в кабинете | `/cabinet/admin` |

Курьер — отдельная проверка (`RequireCourierAccess`), привязка к couriers / logistics, не только role.

Назначение ролей: через админку или API account system.

## Админ-панель

- Логин/пароль из env: `ADMIN_USERNAME`, `ADMIN_PASSWORD`
- JWT с `role: admin` и `username`
- Защита от brute-force: блокировка после N попыток, `remaining_attempts` в ответе
- Создание admin на проде: `ADMIN_SETUP_SECRET` + endpoint create-admin
- Сброс пароля: `reset_admin_password.py`

**Legacy URL:** `/system-portal-924` → redirect на `/admin`

## Регистрация жителя

### SMS (Mobizon)
1. POST запрос кода на телефон
2. Rate limit: `SMS_MAX_REQUESTS_PER_WINDOW`, окно `SMS_REQUEST_WINDOW_MINUTES`
3. Verify → JWT + опционально `WELCOME_BONUS_POINTS`

Env: `MOBIZON_API_KEY`, `SMS_PROVIDER=mobizon`

### Google OAuth
- Redirect URI: `https://<domain>/api/v1/account/google/callback`
- Env: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`

### Согласия
- `accepted_agreement`, `accepted_privacy` — обязательны для compliance
- Legal pages: `/legal/:doc`, static `terms.html`, `privacy.html`

## JWT

| Параметр | Значение |
|----------|----------|
| Secret | `JWT_SECRET_KEY` (обязателен на проде!) |
| Session | `ACCOUNT_SESSION_DAYS` (default 30) |

**Важно:** без стабильного `JWT_SECRET_KEY` все пользователи разлогиниваются после каждого деплоя.

## Авторизация на API

### Публичные endpoints
- GET новости, объявления (опубликованные)
- GET modules, weather, health
- GET storage public images

### Требуют JWT жителя
- Создание жалоб, объявлений
- Кабинет, заказы, такси ride
- Избранное, бонусы

### Требуют admin JWT
- CRUD контента
- PATCH modules
- Push broadcast
- FrontPad settings

### Module guard
`require_module(key)` → HTTP 404 если модуль выключен (кроме panel admin).

## Данные пользователей

### Храним
- Телефон, email (optional), имя
- Хеш пароля (bcrypt)
- История заказов, поездок, бонусов
- Аватар URL (Cloudinary)

### Не храним
- CVV, полные данные банковских карт
- SMS-коды в открытом виде (краткоживущие)

## Медиа и storage

- Загрузка через `/api/v1/storage/*` → Cloudinary
- Компонент `StorageImg` — безопасный рендер с lazy load
- Публичный download endpoint для изображений без auth (where applicable)

---

## Telegram

- Bot tokens только на сервере
- Webhook secret: `TELEGRAM_WEBHOOK_SECRET`
- Разные боты для food, courier, taxi, gastronom

---

## FrontPad (касса)

- Secrets: `FRONTPAD_SECRET`, `FRONTPAD_MENU_SECRET`, `FRONTPAD_ORDER_SECRET`
- Только backend → FrontPad API
- Лог синхронизации: `frontpad_sync_log`

---

## Push (FCM)

- Server key: `FCM_SERVER_KEY` на Railway
- `google-services.json` в Android project (не в git!)
- Broadcast: POST `/api/v1/push/broadcast` (admin JWT)

---

## Frontend security

- Blocklist routes: `/wp-admin`, `/dashboard`, `/panel` → home
- `ErrorBoundary` — не белый экран при ошибке React
- API retry — не logout на network error
- Native: Capacitor secure preferences для чувствительных данных (where used)

## Рекомендации для продакшена

1. Установить длинный случайный `JWT_SECRET_KEY`
2. Сменить `ADMIN_PASSWORD` с дефолтного
3. Включить Cloudinary для всех upload
4. Настроить Mobizon с балансом
5. HTTPS only (Railway/Vercel по умолчанию)
6. Регулярный backup PostgreSQL (Railway plugin)
7. Не включать `SMS_EXPOSE_CODE` на проде (только dev)

См. [PRODUCTION_CHECKLIST.md](../PRODUCTION_CHECKLIST.md)
